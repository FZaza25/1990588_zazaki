# Student Documentation

## 1. Document Introduction
### 1.1 Purpose
**Mars Habitat Automation System**

This project implements an IoT platform for the automated management of a Martian habitat.  
The system collects data from simulated sensors through a Docker container, processes the data through a microservices architecture, and applies automation rules to control habitat actuators.  
The user interface allows real-time sensor data visualization and automation rule management.
